# 02 · 产品定位

## 名称

猫伴 / Cat Companion

## 一句话定位

在 CatPaw Mobile 上常驻的个人层：有长期记忆、能在合适时机主动触达，并在用户授权范围内调用端侧能力与现有 Agent 完成任务，把「用户可控」做成产品核心。

## 它不是

- 现有对话 Agent 的升级版（对话仍保留为入口之一）
- 系统级助理（不抢 Siri 入口）
- 纯云端数字员工（那是已有 Managed Agents）

## 它是

- 用户手机上的「第二大脑 + 执行手臂」
- 轻量、常驻、主动、记忆驱动的日常层
- 重执行仍调用现有 CatPaw Agent / 云端能力

## 优先级用户

1. 内部员工与重度 CatPaw 用户（先验证记忆与主动价值）
2. 本地生活商家主理人（经营异常、评价跟进）
3. 普通个人效率用户
