# 04 · 交互设计

## 原则

1. **解释优先于动作**  
   每次主动触达必须附带简短原因。

2. **确认分层**
   - 低风险（创建本地提醒）：可自动 + 通知
   - 中风险（修改日程）：预览 + 一键确认
   - 高风险（对外发送/下单）：必须二次确认

3. **记忆可见**  
   独立记忆页面，支持筛选、编辑、一键遗忘。低置信度内容先作为候选。

4. **控制面板一等公民**
   - 全局主动开关 + 分场景开关 + 勿扰时段
   - 权限可视化
   - 动作确认策略（默认保守）

5. **触达克制**  
   优先 App 内卡片与锁屏摘要，系统通知次之。

## 关键界面

- **首页**：今日简报 + 主动卡片流 + 快速对话入口
- **记忆**：分类列表 + 详情编辑 + 遗忘
- **助理对话**：保留对话，增加「引用了哪些记忆」提示
- **设置**：权限、主动策略、确认策略、勿扰、动作日志

## 核心流程

### 主动触达 → 确认

1. 系统产生信号（日历冲突 / 任务完成）
2. 决策引擎判断是否值得打扰，并生成解释
3. 以卡片形式出现在首页或推送通知
4. 用户点开 → 看到原因 + 预览动作 → 确认 / 忽略 / 修改
5. 执行结果写入动作日志

### 记忆管理

1. 用户可在对话中显式说「记住……」
2. 或系统从高置信度交互中提取候选记忆
3. 用户在记忆面板中确认、编辑或遗忘
4. 后续任务可引用已确认记忆，并在回复中标注来源
