# 05 · 视觉设计

## 方向

深色优先，暖橙强调，高可读，少装饰。遵循 Apple Human Interface Guidelines，强调轻、快、可预期。

## 色彩

| 角色 | 深色 | 浅色 | 用途 |
|------|------|------|------|
| Primary | #FF7A3D | #FF6B2C | 主行动、品牌 |
| Proactive | #A78BFA | #7C5CFC | 主动卡片 |
| Memory | #38BDF8 | #0EA5E9 | 记忆相关 |
| Success | #34D399 | #1A9B6C | 完成 |
| Warning | #FBBF24 | #D97706 | 需注意 |
| Danger | #F87171 | #DC2626 | 高风险 |
| Background | #0F0F12 | #F7F6F3 | 背景 |
| Surface | #1A1A1F | #FFFFFF | 卡片 |

## 字体与间距

- 大标题 28pt Bold
- 标题 22pt Bold
- 正文 15pt Regular
- 辅助 13pt
- 间距体系：4 / 8 / 12 / 16 / 20 / 24 / 32

## 组件语言

- 主动卡片：左侧色条 + 原因 + 主操作
- 记忆条目：可滑动操作（编辑 / 遗忘）
- 确认流：底部 Sheet，展示预览与影响
- 动效：SwiftUI 原生动画 + Haptic，不做过度装饰
