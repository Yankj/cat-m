# 03 · 产品说明书（MVP）

## 核心能力

| 特征 | MVP 定义 | 非目标 |
|------|----------|--------|
| 主动 | 基于日历、云端任务状态、用户设定关注点，通过通知/App 内卡片触达，并给出可解释原因 | 无限主动、电话、屏幕监控 |
| 有记忆 | 显式 Profile + Episodic 记忆，可查询/编辑/遗忘，并在后续任务中被调用 | 隐式全量行为学习 |
| 能执行 | 端侧：日历/提醒/深链；云端：调用现有 Agent。高风险动作默认确认 | 屏幕自动化、未授权跨 App |
| 可信 | 每次主动带「因为…所以…」；记忆面板、权限面板、动作日志、确认策略可配置 | 黑盒决策 |

## MVP 主动场景

1. 日程冲突 / 即将开始提醒 + 一键调整建议
2. 云端长任务完成或需要确认时推送
3. 用户设定的「每日简报」或关注事项
4. （商家）评价异常 / 经营指标异动提醒

## 非功能要求

- 主动默认保守，宁可少打扰
- 所有副作用动作可追溯
- 记忆与权限对用户完全可见可控
- SwiftUI 原生体验，重点在流畅感与信任感
