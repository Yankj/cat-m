# 07 · 方案与落地节奏

## 架构原则

- 个人助理是「个人层」，重执行调用现有 Agent。
- 决策尽量在云端，信号采集与轻量执行在端侧。
- 信任与控制优先于主动强度。

## Phase 0（4–6 周，内部验证）

- 记忆面板骨架 + 可手动增删
- 日历信号 + 云端任务状态接入
- 2 个主动场景（任务完成、日程冲突）+ 解释卡片
- 权限与确认流基础

## Phase 1（可用 MVP）

- 完整记忆分层与检索
- 端侧原子执行（日历、提醒、深链）
- 4 个主动场景
- 控制面板完善（主动开关、确认策略、动作日志）
- 内部 + 部分商家灰度

## Phase 2

- 更多信号与用户自定义关注点
- 与现有专家/技能的深度调用
- 跨端记忆与状态同步体验打磨

## 核心原则

主动越强，控制面必须越清晰。没有可解释与可控制，主动会被关掉。
