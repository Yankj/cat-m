# 实际部署来源

[2026-10-13 来源 manifest](2026-10-13/SOURCE.json)绑定 Supabase 只读返回的 API v19（50 文件）与 tick v7（43 文件）。这些文件是当时各自部署包的源码快照，未读运行密钥、用户数据，也没有重新部署。

两个包有 14 个同路径文件字节不同。版本差异本身不能证明运行故障；不能把任一包的 `_shared` 当作两者都在使用的共同源码。未来整合须注明选定来源，逐一构建和验证 API、worker/tick，并把任务恢复、许可和调度证据绑定同版。

现有 `services/edge/supabase/functions` 的 v14/P0 来源和历史 manifest 保留。此目录为不可改写的部署来源；功能改动应进入新版本的维护源码，再通过验收及发布流程建立新记录。

上游 OpenMuse 的固定来源与 MIT 声明仍见仓库 `vendor/openmuse`。快照只保留函数源码和公开依赖声明；个人机器路径、项目连接配置和 credentials 不在本目录。
