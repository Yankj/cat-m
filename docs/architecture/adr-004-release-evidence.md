# ADR-004：维护可复现快照与精选证据

状态：本地准备采用，2026-10-11。

下述是历史资产版本与证据维护规则；当前进展只更新 [主计划](../status/master-plan.md)。新chat/原生/记忆活跃代码不复制，最后源码冻结和局部PASS也不自动构成产品签收。

当前代码基线是已交付 v1、façade r2与独立冻结r3客户端。活动客户端阶段先只读盘点；其验收终态、最后源码与最终ZIP hash核对后，在 `apps/ios-openmuse-demo` 整合，保留v1。最终源码实际编译结果与更早报告分开，不抢改、不合入正在写入的目录。

长期仓库保留源码、规格/设计、决策、验收标准、来源 hash 和精选合成图。临时构建、全量截图/树、设备记录、zip 和每轮日志不进入提交；少量 TAP/领域输出与来源 hash 用于复核已声明结果。含绝对个人路径的报告重写为可移植摘要，保留原文 hash/本地审计来源，避免把改写日志称逐字原文。

没有自行给自有代码加对外许可；不改变私有可见性、权限或远端。当前所有变更仅为本地待提交差异。
