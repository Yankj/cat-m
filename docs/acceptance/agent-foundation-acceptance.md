# 通用 Agent 底座验收标准

版本：AF-1，2026-10-13；对应[spec](../product/agent-foundation-spec.md)。机器可读用例见[acceptance.json](agent-foundation-acceptance.json)，当前执行结果只更新[主计划](../status/master-plan.md)。以下是执行合同，尚未运行的用例不能被表格本身记为通过。

## 判定与证据

结果只能是 PASS、FAIL、NOT_RUN 或 BLOCKED；明确写阻塞条件。代码编译/静态、合成单测、Simulator UI、loopback HTTP、真实云端数据库/模型、物理手机分别标证据层。一个低层结果不能关闭高层用例。

每次测试绑定 sourceCommit 或 dirtyFiles SHA256、API deployment、protocol version、app version/build、环境、case ID、开始/结束时间和结果。真实发送另记 operation/turn/task、受理/terminal、provider/model/usage（若返回）、模型调用增量；无记录时写 unavailable。日志不包含 token、私人材料、图片正文/base64 或签名 URL。性能证据记录采样方法、样本数、分位数；Simulator 回调不作真机呈现帧。

错误或 unknown 用原 ID 做只读核验，禁止为凑结果重发。用人工构造文本、图片与公开测试资源。每个真实调用先固定数量上限和结束条件；现有路由失败后停止并给出失败段，再讨论切换。

| AF-A15 / R09,R08 | 设置已知时间提醒；后台触达；点击入口；拒绝通知权限 | 系统实际提醒回同事项；拒绝可在App内收件箱使用。云端变化推送需单独APNs实测，未做须明确能力缺失 |
