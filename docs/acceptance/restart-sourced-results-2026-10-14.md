# W31a / W32a：受控公开来源、原生成果阅读与精确决定合同

日期：2026-10-14。候选 `AF-W31-ACTION-20261014-03`，基线 `1c3bb15392f2d893db5ae2be0288822af796878c`，分支 `feat/s03-sourced-results`。修改源码、测试和实际日志的 hash 见 [RESULT](evidence/sourced-results-20261014/RESULT.json)；当前进度仅见 [master-plan](../status/master-plan.md)。本片是维护源码、离线事务端口和原生 Simulator 候选，不关闭 W31/W32、CP-01 或任何真实产品验收门。

## 实际行为

- 现有对话新增有条件登记的 `delegate_sources_v1`。只受理用户原会话明确提供的 1–3 个 HTTPS URL，固定原 turn/run/task/request、计划版本和来源编号；模型不能发明来源或扩大允许域名。未配置公开来源策略时不提供这个工具，原文本 route 及其 hash 保持不变。
- 维护读取器按显式非敏感策略限定域名、路径和固定公共 IPv4；直接 TCP/TLS、原域名证书/SNI、有限手动重定向和无身份 GET。禁止私网、元数据地址、URL 凭据、常见签名/凭据查询参数、Cookie/Auth/代理与隐式 DNS/fetch 回退。响应头、原始正文、提取文本、跳转次数和耗时均有界；HTML 提取使用线性扫描，不执行网页内容。
- 每项真实读取端口调用先持久记录原始 dispatch，再把实际返回字节、正文 hash、文本 hash、时间、最终 URL、计划和策略绑定为来源回执。恢复只消费原回执；未确认的原始读取显示 unknown，不能重新发送。引用须是当前执行版本的实际文本子串，并覆盖全部受理来源，模型给出的 URL/hash/“已阅读”不能代替读取回执。
- 成果正文、来源、引用、实际 compose/save 步骤回执和 model cursor 在既有 scoped Store 的同一事务内保存。最后写入等待期间撤权或租约取消会整组回滚；完整旧 worker 也明确保存续跑时间。计划修改仍在安全点应用：v1 回执不能完成 v2，新版重新取得绑定其版本的来源回执，原 task 不变。
- 原生流按 UTF-8 原字节的 ASCII CR/LF 边界拆事件，保留合法 NEL/U+2028/U+2029 和完整正文 hash；有界行、非法 JSON 与未结束行 EOF 都不能制造完成。三种委派名字分别覆盖空正文、BOM 空白、NEL、实际正文、冷重开和同工作续聊，原 turn 的 hash/任务绑定不放宽。
- 原生成果进入独立阅读页，按 artifact ID/version/hash 打开选定版本；返回不偷偷切到最新版。正文按纯文本展示，复制/分享由用户操作。底部来源入口打开系统 sheet 的列表与详情，展示请求/最终 URL、读取时间、正文 hash 和摘要；只有受支持、完整且可核对的来源元数据才启用链接。这里的元数据核对不是手机独立重抓网页的证明。
- 阅读页保留历史版本与正文 hash 的展开入口；v2→来源详情→v1→v2→原会话返回时保留聊天草稿，不增加发送。紧凑成果卡、原生 NavigationStack/sheet、放大字体下的可达性与返回路径同步交付。未知/缺失/冲突版本不跟随最新版；不支持的来源格式保留正文并安全降级。
- 新增独立 `catpaw.task-action.v1` 精确决定服务与读写端口。当前只有 `calendar.create.v1` 的参数/目标合同：冻结原来源、计划、成果 hash、设备/环境/日历/目标快照、时间/时区/提醒和到期。原 operation UUID 与 payload hash 固定，重复只读原决定；CAS、拒绝、到期、目标替换、计划/许可/成果改变和迟到决定均有回归。
- 动作提议/决定需要显式可信目标核验端口，默认未配置即拒绝，不由模型安装。`approved` 仅是批准事实，后续为 `waiting_device`，`execution_authorized=false`、registry `executable=false`；本片没有 EventKit 执行器、系统效果回执或新的原生审批入口，不能把批准称为任务完成。新 ledger 加入删除屏障与清理清单，但本片不宣称生产物理清除已完成。

## 验证与证据边界

最终测试、构建、静态与治理结果以 RESULT 的逐项日志/hash 为准。后端全量维护测试使用现有 Deno 和明确给定的 public cache，cached-only、deny-net；HTTP、TLS 字节、模型和事务存储均为显式合成端口。它们检验实际维护类和有界 worker 接线，没有调用真实公开站点、Auth、模型、生产 PG 或云端调度。

保留两项独立审查发现的负对照：在忽略的执行副本中去掉旧完整 worker 的续跑时间，第二次 tick 无法继续；保留续跑修复但去掉最后写入后的权威复查，取消/撤权时会留下成果。维护源码修复后的同类回归通过。第一次组合负对照把缺失时间转为 NaN 测试时钟而导致测试 worker 等待，已只停止本任务的该 Deno 进程；后续拆分负对照正常终止，不当作生产故障。

原生初轮编译和单元通过，两个新 UI 初轮失败：一个来源/历史 DisclosureGroup 外层标识覆盖子元素，另一个放大字体路径没有先把离屏 lazy 卡滚回。修正层级与测试可见区域后复验，保留初轮失败和最终附件。旧含真实路径的 UITest 只迁移成果入口/阅读 hash 选择器，本轮没有执行这些真实测试。新 UI 使用 DEBUG 合成同任务 v1/v2，来源链接未点击，没有外部网络。

大字号路径先通过既有侧栏开关收起键盘，核对长聊天草稿/hash 不变；滚动手势须命中 transcript 实际区域，排除透明边缘、composer 与“回到最新”固定浮层。r5 的七项测试通过后，截图发现来源 sheet 没有继承 fixture 的辅助字号，仍落中档；没有据此关闭最大字号门。已在 Reader 显式把父字号传入 sheet，最终测试增加大档导航位置、来源行高度和实际链接可滚动到达断言。只证明本次合成 accessibility5 路径，不代替系统字号、VoiceOver、完整手势/动效或真实手机验收。

新增本机 loopback wire 矩阵实际复现 NEL 被 `AsyncBytes.lines` 截断 JSON 的缺陷；未改成转义字符串掩盖输入，修为 ASCII 分帧后再验原字节。另有既有 wire 断言过期：服务返回原 turn 的 `failed/error=not_configured` 且无消息/任务，但随后 fresh readyz=true 表示可连接、模型尚未验证。测试改核原失败与零伪完成，不再要求已被既有连接实现取消的旧缓存状态，未为此修改生产连接状态。最初默认沙箱阻止脚本后台进程/loopback 与 Xcode 系统缓存，均只在现有工具的本地合成范围提升后复跑，没有授权或发送外部请求。

候选敏感扫描命中的 URL userinfo 与 `access_token=fake` 均是拒绝用例的明确合成字符串，按精确 path/line/整文件 hash 人工复核，未删除负向用例或放宽规则。运行输出和模拟器截图留忽略的 build 目录；截图版本、fixture 来源、hash 和限制见 RESULT，不能关闭真实 iPhone 验收。
