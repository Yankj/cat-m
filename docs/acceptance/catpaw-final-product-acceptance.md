# 小咪终版质量与竞争优势验收

版本：FINAL-1，2026-10-13，对应[终版规格](../product/catpaw-final-product-spec.md)，机器映射见[JSON](catpaw-final-product-acceptance.json)。这是待执行合同，实际结果只在[主计划](../status/master-plan.md)。当前AF-1-G3-UX1的18功能／12UX／3组合路径保留；不得用下面的质量项取代基础用例。

## Goal 判定

FINAL-G1＝全部基础用例同候选通过＋FQ-01–09及其[CG-A01–10必需细分](conversation-generative-ui-acceptance.md)全通过；FINAL-G2＝BP-01–08记录齐备并满足具名比较规则；FINAL-G3＝G1/G2同候选成立。基础AF-G5完成只支持“底座已验收”，不自动支持“优于Codex/dots/Grok Bot/Muse”。比较不能执行时保留未验并限定对外结论，不改写为胜出。

P0包括越权、隐私／数据丢失、双写、假成功和主要路径不可继续；P1包括稳定复现的主要交互／恢复／可访问性失效。必需用例任一FAIL阻止G1，无P0/P1仅是额外条件，不代替完整用例通过。NOT_RUN/BLOCKED不算PASS。

7天记录和竞品对照同样须另列具体测试资源／操作清单；本轮只制定标准，未自动创建调度、发消息或招募参与者。设备缺失、原路由性能不足或托管未确定要记录实际阻碍，不能调整阈值凑PASS。

## 八条同任务竞争对照

目标产品分开识别：ChatGPT中的Codex mobile、OpenAI dots、xAI Grok Bot、Meta Muse。CopilotKit/OpenBot／OpenMuse是开源参考，不代替这些闭源产品的真实表现。记录版本／日期／平台／账户计划／可用能力／使用模型（不可见写unavailable）。官方网页只证明公开功能边界，不能当配对测量。

| ID | 固定任务与期望结果 | 主要指标 |
|---|---|---|
| BP-01 对话阅读 | 同一人工短问＋长中文／表格，生成中向上读并复制 | 完成正确性、首字/结束时间、锚点失效、修复操作数 |
| BP-02 流中决定 | 缺少日期/格式的同一任务，选择／填写后继续 | 首个可操作决定时间、有效交互/切页数、输入丢失、同工作续接 |
| BP-03 审批恢复 | 准备受控写，关闭再重开，修改目标、拒绝/允许 | 找回耗时、找回点击数、旧批准拒绝、真实effect数；缺失能力单列 |
| BP-04 手机改计划 | 手机内修改任务范围和已设跟进时间/指令 | 是否全程手机完成、桌面依赖、修改正确性、用户操作耗时 |
| BP-05 成果查收 | 同三份公开输入资料，离开再从原对话/活动打开与改稿 | 关键事实正确率、有效来源、成果入口操作数、版本冲突/重开一致性 |
| BP-06 克制主动 | 相同关注合同，基线/无变化/变化/重复/静默/失败 | 有效提醒/漏报/重复/噪声、due和检测延迟、why-now可解释性 |
| BP-07 记忆控制 | 相同显式偏好，跨会话使用、更正、忘记 | 来源可查、使用正确性、旧值复活、完成控制操作数 |
| BP-08 工作接续 | 同两步工作，离开手机/弱网后回来，停止后核对 | 完成率、恢复耗时、重复意图/效果、错误下一步理解与修复 |

输入、结束条件与真值先冻结；不在看到结果后换题。每个适用任务至少5组配对，AB/BA交替顺序，重置测试上下文与缓存条件；允许产品用各自正常模型／交互，但记录差异。不付费开新计划或引入未经确认账户/资源来完成比较。

**优势声明规则：**对每个具名参照，记录全部BP的适用性；至少4项共同可执行的任务有有效配对。关键正确性、授权、真实effect、数据保留与恢复不能劣于参照；至少2个预先登记的相关体验维度（用户主动操作时间、必要操作/切页数、决定找回时间、成果查收时间）中位数改善≥20%，且用户能理解工作状态。完成率/功能覆盖与速度分开报告，不合成一个总分遮盖失败。

NOT_SUPPORTED是已核实的能力覆盖差异，不记成耗时0或任意胜分；未获得实际版本／账户是NOT_RUN/BLOCKED，不能宣称胜出。正常产品UI与严格受控环境的故障注入分别记录，不能把我们的故障注入与竞品正常路径混作配对。5组是个人产品范围的初步证据，不能推导全市场或统计显著性；措辞限定“在这些任务和版本上”。
