# Codex iPhone 对标体验验收

终版交互回答按[CGUI-1](../design/conversation-generative-ui-spec.md)及[CG-A01–10](conversation-generative-ui-acceptance.md)补验表图、确定试算、显式跟进和恢复。原12项UX保持，CG细分纳入FINAL-G1，不用Web提案关闭原生用例。

版本：UX-1，2026-10-13。对应 [设计规格](../design/ios-codex-experience-spec.md)；机器用例见 [contract.json](ios-codex-experience-acceptance.json)。AF-U01–12 是AF-A17的必需细分要求，也共同支撑AF-A02/04/06/16，不能以局部布局检查关闭这些端到端用例。

**AF-GD和最终AF-G5必须通过全部AF-U01–12。** 主计划维护实际状态。设计预览只能签收设计方向；原生真机交互必须在对应发布候选重验。

| ID | 操作与检查 | 明确通过条件 |
|---|---|---|
| AF-U01 信息架构 | 新/旧对话→侧栏→任务/成果/记忆/跟进→返回；查优先事项 | 默认单列对话，无强制手建委托；常用卡一次点按进入对应详情；等待/未读/运行清楚且不重复计数；返回保留草稿/位置 |
| AF-U02 主对话 | 空页、短问答、长中文、夹工具/任务卡；浅深色 | 首屏以正文/输入为主；用户轻气泡、助理直接阅读；无常驻调试面板；正文/卡/动作符合指定层级且内容不裁切 |
| AF-U03 输入与附件 | 中文IME、五行以上草稿、真实选图/替换/移除、键盘收起/切页；队列两条 | 不误发marked text；显式Send；图片缩略图有界且完整比例可读；队列默认一行；未发消息不重复显示；草稿保留 |
| AF-U04 流式阅读 | 正文增量时向上读；回到底部；长表格/代码/链接/复制 | 阅读锚点稳定且可回最新；无正文倒退或重复；只表格/代码横滚；来源能打开并回原位置；正常回复操作可用 |
| AF-U05 侧栏 | 菜单打开→遮罩关闭→侧滑→切会话→搜索无结果→清空；详情边缘返回 | 抽屉宽度符合合同，动作44pt可达；关闭/返回手势无冲突；搜索空状态明确；切换不丢草稿或污染会话 |
| AF-U06 任务/计划 | 从消息看计划→修改条件→暂停/恢复→失败/等用户/等设备 | 状态与实际对象一致，当前步骤/等待原因可读；控制名称区分；每种等待有下一步；无虚构进度或无限spinner |
| AF-U07 审批 | 打开/关掉/重开/拒绝/允许/过期/未知；键盘与最大字号 | 本次动作/目标/参数和影响可核对；关闭不决定；按钮明确且可达；提交先处理中，回执后成功；unknown只核对，不盲重发 |
| AF-U08 成果 | 原对话/活动打开同成果→表格/来源→版本→继续修改→返回 | 同ID/version，内容优先；来源/版本可读；修改带同成果引用返回；大内容可滚动，主动作不挡正文 |
| AF-U09 记忆与跟进 | 查看来源→更正/删除；查看下次时间→暂停/结束；空/错误 | 使用同一原生列表/详情规则；状态和反馈可理解；无变化不产生噪声；可以查到既有结果；空页可填对话示例 |
| AF-U10 视觉一致性 | 同版浅/深色截图与主色/字体/间距/圆角/图标审阅 | A1保留；组件使用semantic tokens；无未解释的样式漂移；正文/关键次字4.5:1、必要非文字辨识3:1；实际渲染记录支持 |
| AF-U11 尺寸与可访问性 | 375/390/430pt；小屏键盘；最大辅助字号；VoiceOver；Reduce Motion | 不裁切主动作、不产生页面横滚；大字号按钮可纵排；朗读标签/顺序能完成发送/审批/阅读；减弱动态后无必要外动画 |
| AF-U12 转场与恢复 | sheet关闭/NavigationStack返回；键盘动画；活跃流后台5s/30s与重开 | sheet和详情类型一致，恢复回同对象/位置；输入随键盘不双计安全区；本地反馈≤500ms；真实帧/恢复满足AF-A04/05且不重发 |

2026-10-13 源码研究补充现有用例的必查状态（不增删12项）：AF-U06 将计划逐步记录与实际成果对照，任务终止不令未执行步骤全部变绿；AF-U07 在工具活动折叠、离线待决、执行已成功但续聊失败、已开始但结果未知时重开，分别继续同结果或只读核对；AF-U08 验证临时链接过期后重取、读取失败后恢复、改稿期间旧回包和预期版本冲突，保留草稿及当前页面。三项同时覆盖生成中卡没有可提交动作、未知卡降级；“成果已保存”与“已打开阅读”分别呈现。依据见[四仓决策报告](../research/copilotkit-four-repo-decision-update-2026-10-13.md)。

## 设计修订R1的必查行为

[产品评审](../design/product-experience-review-2026-10-13.md)补齐以下断言，仍归原12项与FQ-06，不新增验收ID或改变真实证据要求；[JSON](ios-codex-experience-acceptance.json)的design_assertions同步记录。以下均为待执行标准。

| 既有用例 | 补充操作 / 必须成立 |
|---|---|
| AF-U01 / U05 | 从对话找待决、运行工作与成果；活动统一入口，资料与管理可展开，零事项不占空卡；计数不重复，返回保留原位置 |
| AF-U02 | 首次打开可写草稿，示例只填入；必需Auth/配置不冒充可跳过；权限按需出现；已给范围不重复问，非关键格式用默认值；普通问答无强制计划/仪表盘 |
| AF-U03 / U06 | 输入聊天草稿→进入某工作修改→编辑→退出→再进入；两份草稿分别保留，关联工作明确，退出无命令；发送后受理与安全点应用分开显示；日程不可配研究计划 |
| AF-U06 | 一项工作主流只一个稳定摘要，当前待决突出，已回答卡压缩可展开；多待决有剩余数量/入口；没有每步骤新插大卡或全部状态同时强调 |
| AF-U07 | 待决出现时不抢占阅读；点开预览→大字号滚动→关闭/拒绝/允许；正文与决定区分开，按钮可达；unknown无成功反馈；真实回执一次反馈 |
| AF-U08 | 成果先实际内容/结论，来源/版本可查；复制/系统分享当前内容可用；未接文件格式无假导出；部分完成说明缺项；分享不触发写工具 |
| AF-U09 | 编辑频率/条件草稿→切静默→继续编辑；未保存字段不丢，不误显示已保存；回App只有真实变化摘要，无变化不造消息 |
| AF-U10 / U11 / U12 | 正文/决定/摘要/元数据层级可辨；控件/导航材质不污染长文；系统降低透明度/增加对比生效；VoiceOver不逐token打断、焦点不被状态夺走；关闭触觉仍可理解真实结果 |

可在现有FQ-06窗口中观察首次使用者是否独立解释“正在做什么、是否需要我、成果在哪里”；若有人提示，记录帮助次数，不能记为独立完成。参与者、模型调用与安装沿具体授权；没有执行时保留未验，不凭设计作者判断签收。

## 设计修订R2的视觉与动效检查

[视觉实施附录](../design/taste-visual-motion-r2.md)的M01–M10进入原12项，没有新增签收数量。以下是原生候选的待执行标准；CSS屏框/动效和token对比不作产品PASS。

| 既有用例 | R2操作与必须成立 |
|---|---|
| AF-U02 / U10 | 同版正文/工作行/当前待决/成果层级明确，沿A1与冻结色；字体和圆角按组件角色，表图与正文不叠玻璃，必要控制边界达到3:1 |
| AF-U03 / U12 | 输入长文、中文IME、进出修改/队列/键盘；输入器安全区不双计，焦点与两份草稿保留，主动作至少44pt；没有整页弹跳 |
| AF-U04 | 向上阅读时卡收起/新成果/流段落出现；ID、位置和输入稳定，锚点上方高度变化需补偿；历史重开不重播成果进入运动；没有逐token动效/公告 |
| AF-U05 | 抽屉点按/拖拽与详情返回，不与系统手势冲突；遮罩与背景焦点隔离，关闭回原入口；reduce后仍能操作 |
| AF-U07 | 375pt、最大辅助字号、键盘下滚审批正文，三个决定动作可达；关闭保留入口；processing不成功，unknown只核对；真实回执只一次完成反馈 |
| AF-U08 / U09 | 成果内容先读、来源/版本可查；继续修改回同工作；跟进/记忆沿同排版/控件规则，编辑与静默不丢值，错误能重读同结果 |
| AF-U10 / U11 / U12 | 375/390/430浅深色＋最大系统字号、Reduce Motion/Transparency/Increase Contrast、VoiceOver实操；实际像素对比和44pt命中区有记录，文字换行不缩字，系统转场/键盘不叠重复自定义运动 |
| AF-U12 | 原生有限运动和帧证据按M表/父用例记录；动态设置、无声/触觉关闭仍懂状态；恢复历史/后台回来不把旧回执重播为新完成 |

最低证据：同版源码/dirty hash、appBuild、场景ID、设备/尺寸/字号/主题、实际操作与结果、必要合成截图/视频hash、对象/动作关联、限制。真实网络/对象行为按父用例的证据层，不用静态fixture替代。

设计审阅必须把具体问题定位到页面、状态和操作：例如“390pt深色、键盘开启、审批主动作被盖住”。不能以“像Codex”或单个相似度总分签收。每个未符合的必需项标FAIL；若用户选择修改设计范围，先版本化记录新合同。

可点按预览的检查范围仅为布局/路由/状态提案，不证明原生触控、系统键盘、VoiceOver、模型或设备动作。最终通过需要真实iPhone记录；Simulator可补充另外两档尺寸，不能冒充三部物理设备均已验证。
