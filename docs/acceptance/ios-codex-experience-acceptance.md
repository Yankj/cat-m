# Codex iPhone 对标体验验收

版本：UX-1，2026-10-13。对应 [设计规格](../design/ios-codex-experience-spec.md)；机器用例见 [contract.json](ios-codex-experience-acceptance.json)。AF-U01–12 是AF-A17的必需细分要求，也共同支撑AF-A02/04/06/16，不能以局部布局检查关闭这些端到端用例。

**AF-GD和最终AF-G5必须通过全部AF-U01–12。** 主计划维护实际状态。设计预览只能签收设计方向；原生真机交互必须在对应发布候选重验。

| ID | 操作与检查 | 明确通过条件 |
|---|---|---|
| AF-U01 信息架构 | 新/旧对话→侧栏→任务/成果/记忆/跟进→返回；查优先事项 | 默认单列对话，无强制手建委托；常用卡一次点按进入对应详情；等待/未读/运行清楚且不重复计数；返回保留草稿/位置 |
| AF-U02 主对话 | 空页、短问答、长中文、夹工具/任务卡；浅深色 | 首屏以正文/输入为主；用户轻气泡、助理直接阅读；无常驻调试面板；正文/卡/动作符合指定层级且内容不裁切 |
| AF-U03 输入与附件 | 中文IME、五行以上草稿、真实选图/替换/移除、键盘收起/切页；队列两条 | 不误发marked text；显式Send；图片缩略图有界且完整比例可读；队列默认一行；未发消息不重复显示；草稿保留 |
| AF-U04 流式阅读 | 正文增量时向上读；回到底部；长表格/代码/链接/复制 | 阅读锚点稳定且可回最新；无正文倒退或重复；只表格/代码横滚；来源能打开并回原位置；正常回复操作可用 |
| AF-U05 侧栏 | 菜单打开→遮罩关闭→侧滑→切会话→搜索无结果→清空；详情边缘返回 | 抽屉宽度符合合同，动作44pt可达；关闭/返回手势无冲突；搜索空状态明确；切换不丢草稿或污染会话 |
| AF-U06 任务/计划 | 从消息看计划→修改条件→暂停/恢复→失败/等用户/等设备 | 状态与实际对象一致，当前步骤/等待原因可读；控制名称区分；每种等待有下一步；无虚构进度或无限spinner |
| AF-U07 审批 | 打开/关掉/重开/拒绝/允许/过期/未知；键盘与最大字号 | 本次动作/目标/参数和影响可核对；关闭不决定；按钮明确且可达；提交先处理中，回执后成功；unknown只核对，不盲重发 |
| AF-U08 成果 | 原对话/活动打开同成果→表格/来源→版本→继续修改→返回 | 同ID/version，内容优先；来源/版本可读；修改带同成果引用返回；大内容可滚动，主动作不挡正文 |
| AF-U09 记忆与跟进 | 查看来源→更正/删除；查看下次时间→暂停/结束；空/错误 | 使用同一原生列表/详情规则；状态和反馈可理解；无变化不产生噪声；可以查到既有结果；空页可填对话示例 |
| AF-U10 视觉一致性 | 同版浅/深色截图与主色/字体/间距/圆角/图标审阅 | A1保留；组件使用semantic tokens；无未解释的样式漂移；正文/关键次字4.5:1、必要非文字辨识3:1；实际渲染记录支持 |
| AF-U11 尺寸与可访问性 | 375/390/430pt；小屏键盘；最大辅助字号；VoiceOver；Reduce Motion | 不裁切主动作、不产生页面横滚；大字号按钮可纵排；朗读标签/顺序能完成发送/审批/阅读；减弱动态后无必要外动画 |
| AF-U12 转场与恢复 | sheet关闭/NavigationStack返回；键盘动画；活跃流后台5s/30s与重开 | sheet和详情类型一致，恢复回同对象/位置；输入随键盘不双计安全区；本地反馈≤500ms；真实帧/恢复满足AF-A04/05且不重发 |

最低证据：同版源码/dirty hash、appBuild、场景ID、设备/尺寸/字号/主题、实际操作与结果、必要合成截图/视频hash、对象/动作关联、限制。真实网络/对象行为按父用例的证据层，不用静态fixture替代。

设计审阅必须把具体问题定位到页面、状态和操作：例如“390pt深色、键盘开启、审批主动作被盖住”。不能以“像Codex”或单个相似度总分签收。每个未符合的必需项标FAIL；若用户选择修改设计范围，先版本化记录新合同。

可点按预览的检查范围仅为布局/路由/状态提案，不证明原生触控、系统键盘、VoiceOver、模型或设备动作。最终通过需要真实iPhone记录；Simulator可补充另外两档尺寸，不能冒充三部物理设备均已验证。
