## 配色、字体与间距

主方向：白／近黑阅读面，灰色临时面，亮蓝动作，深蓝本人消息。JPEG近似样本包括黑底、约`#3567EE`按钮与约`#020562`本人气泡；R5适度调亮本人气泡。下表均为cat候选，不是官方规范。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 阅读底／正文 | `#FFFFFF`／`#202020` | `#050505`／`#F2F2F2` |
| 辅助正文 | `#626262` | `#A3A3A3` |
| 输入／内容面 | `#F7F7F7` | `#141414` |
| 智能交互／临时面 | `#F7F7F7` | `#181818` |
| 本人消息底／字 | `#E8EFFC`／`#244987` | `#102052`／`#F2F2F2` |
| 发送主动作／图标 | `#3567EE`／白 | `#3567EE`／白 |
| 文字操作／焦点 | `#315BCA` | `#7E9CFF` |
| 审批确认 | 深底白字 | 浅底深字 |

正文使用系统字体，中文随系统采用PingFang，不给中文加入字距。默认正文17、行高约1.6；段间24、主要块间28、正文页边16–20。回答结论保持同字号，用少量600字重突出对象；普通对话不使用海报式标题。过程15、辅助13–15、导航17、表格16起。列表项间8–10，表格行上下各12，标题前24／后12。以上是设计起点：网页用px调试，Swift用语义文本样式与系统字号，不能把截图像素直接当iPhone pt。

本人气泡不超过可读内容区88%，内边距12×16、圆角24。助手正文没有全段底板。来源视觉胶囊约24高，但点按区域44；行内目标扩大不能挤大整行或盖住相邻链接。表格自身横滚，页面不横滚。深色蓝文字与蓝按钮分用不同色值，普通小字不直接使用按钮蓝。

## 导航、输入和菜单

顶部左侧44菜单、中间短会话名、右侧新对话＋更多复合胶囊。图标属于一个系统家族，Swift使用SF Symbols与可读标签。导航占自己的安全空间；滚动边缘渐隐只帮助分隔，首段不会被悬浮控件遮住。材料仅在导航、临时控件层；正文、表格、智能卡不铺玻璃。降低透明度提供实色面。

| 输入状态 | 行为 |
|---|---|
| 空草稿 | 紧凑单行：左附件、中间文字、右发送。空白时发送禁用，不能替换成语音波形或另一个未解释动作。 |
| 正在起草 | 内容上行，附件／表达偏好／展开编辑／发送下行；最多约五行后内部滚动。表达偏好只影响草稿，不切模型。 |
| 全屏编辑 | 同一草稿对象、标题和返回；关闭与返回保留文字和光标，不自动提交。 |
| 正在回答 | 仍可写草稿，发送进入明确待发；独立停止控件有标签。停止输出不取消持久任务。 |
| 引用／修改 | 输入器上方具名关联条，聊天和工作修改草稿分别保存；退出不提交。 |
| 附件 | 同容器有界预览、替换和移除；相机／照片／文件／工具按实际接通状态出现。仅示意菜单不申请权限。 |

消息尾部依次为复制、反馈、分享、更多、来源。更多属于当前回答：选择文字、引用、在新对话继续、来源，以及有合同后才开放的重新回答。未完回答复制当前已显示部分。系统分享只分享内容，不触发工具或包含审批授权。

会话菜单属于整个会话：分享、置顶、附件、查找、归档、删除；空间归属是候选。当前对话查找只搜索已加载内容，无结果不代表全历史无结果。归档、删除、暂停任务各自说明对象和后果。所有菜单贴近来源，前景独占、关闭恢复来源焦点和位置；点击引用后才切到输入焦点。附件菜单、消息菜单、会话菜单不能混用动作。

## 思考与执行过程

“思考”在产品上表现为可核验的处理进展，不展示隐藏推理，不生成假过程。首层最多一行：`正在整理要求`、`正在读取资料`、`找到2份资料`、`需要你确认`；计数来自真实工具事件，不能由正文猜测。无可见事件时说明`正在等待回复`。展开显示事件摘要、开始／结束事实、来源关联、失败与重试边界；完整计划仍进任务详情。

| 状态 | 显示与控制 |
|---|---|
| 等待／处理 | 一句说明与轻状态标记，无百分比、无无限成功预告；超时提供核对／继续等待。 |
| 搜索／读取 | 实际工具名称、真实数量及已读来源；失败不把未读网页画成已读。 |
| 正文流 | 同messageID增量追加，已有文字不回退；上读保持锚点，最新内容给轻入口。输入、卡片值与焦点不重建。 |
| 本次正文结束 | 收起活动标记、保留摘要与来源；工作状态独立，不将所有计划步骤变绿。 |
| 停止输出 | 保存部分正文，说明范围。现停止观察不能直接命名取消生成。 |
| 请求暂停 | `申请暂停→等待确认→权威已暂停`。本地fence与已发请求都不等于服务已停。 |
| 失败／部分完成 | 保留已完成成果和未完成项；unknown核对原请求，不能盲目重发写入。 |

耗时可显示有依据的“已等待”。当前`ConversationTurnEvent`没有timestamp／elapsed，不能直接实现截图中的“思考了15s”；需补服务时间事实和重连恢复。本地样机只把实际浏览器回放时间命名为“本地回放”，不冒充模型耗时。VoiceOver不逐token公告，状态变化按语义节流。

## Swift实现顺序与成本

| 单元 | 现有基础／缺口 | 相对成本 |
|---|---|---|
| 字体、间距、蓝色角色、顶部复合控件 | 现有Swift宿主与语义样式；冻结色资产不覆盖，新角色先独立映射 | 低 |
| 消息复制、选择、引用、局部查找 | 原生TextKit与草稿；局部查找限定已加载正文 | 低–中 |
| 输入增长、全屏编辑、键盘锚点与附件预览 | 已有图像输入／草稿；需同一对象和safeAreaInset验证 | 中 |
| 来源面板、搜索事件、真实耗时 | 现HTTP只投影delegate_task／agent_status；需真实受控事件和时间合同 | 中–高 |
| 停止输出、暂停回执 | stopObserving仅停观察；独立任务service有pause/resume，尚需接对话详情 | 中–高 |
| 新对话引用／正式分支 | 前者可复用新对话；后者需父子关系、快照和权限合同，不能继承旧审批 | 中／高 |
| 重新回答 | 需要显式新turn；unknown先核对，已发生效果不可重放 | 中–高 |
| 文件、相机、工具、空间管理 | 独立接入候选；不因参考图扩展账号、付费计算或部署范围 | 中–高 |

先交付正文／输入／来源与消息动作，再接真实过程投影和任务控制；不把候选功能画成生产可用。R5样机里的样例照片／文件、置顶、反馈、来源与状态只在RAM中。归档／删除仅展示具体确认预览，无删除执行。相机、重新回答、空间入口禁用；正式版隐藏未接入口。没有语音对话、模型请求、上传、系统分享发送或第三方账户行为。

## 验证范围

R5复用原R4 `motion.js`、`app.js`、基础CSS和SVG，以及R4.1覆盖层；新增独立composition与呈现脚本，不改历史候选。以小屏浅深色、大字、键盘占位、过程、菜单、来源、智能试算和审批复查布局与草稿／焦点。网页磨砂不等于Liquid Glass，键盘占位不等于原生IME，网页字号不证明最大Dynamic Type。全屏编辑的原生选区／光标恢复、正式触觉、系统手势、真实流、持久恢复和全部release验收仍需同版原生证据。版本记录见[日期证据](../acceptance/evidence/mobile-reference-20261013-r5/RESULT.json)。
