# Catpaw 产品与视觉交互评审

日期：2026-10-13；设计修订 R1。按用户给出的“聚焦、直觉、承担复杂性、控制权、保护时间与成果、全过程工艺”标准评审。本文记录理由与取舍；可执行规则已写回 [FINAL-1](../product/catpaw-final-product-spec.md)、[UX-1](ios-codex-experience-spec.md)和[CGUI-1](conversation-generative-ui-spec.md)，不成为第四份产品规格。实时状态只在 [master-plan](../status/master-plan.md)。

## 结论

Catpaw 已有扎实的信任与执行合同：同工作身份、持久审批、unknown 核对、来源版本、记忆删除、无变化静默。conversation-first 和 Swift 优先应当保留。

当前规划最需要补的是**产品的选择与层级**：为谁解决什么问题，哪些决定由产品承担，什么时候让用户介入，以及怎样把成果交到用户手上。六种卡和三种可视化都实现，并不自动形成一个轻松的产品。

本版体验承诺改为：

> **把你交代的事变成可用成果；需要你时说清楚，回来时接得上。**

主要使用者是需要读资料、形成判断并持续跟进事情的个人；典型处境是在手机上短暂交代、途中调整、稍后查收。产品情绪是从容、清楚、可靠。首个价值路径为“三份公开资料 → 可读、有来源的一页报告 → 同成果改稿”；跟进与日程在这条工作循环中自然延伸。保留全部 18A／12U／3CP／9FQ／10CG 与终版比较门，聚焦展示与实施次序，不删除必需能力。

## 具体体验应该怎样走

| 时刻 | 用户看到 | 用户动作 / 产品承担的复杂性 |
|---|---|---|
| 打开 | 恢复上次对话；新对话一句“今天想交给我什么？”；最多两条实际可用示例 | 直接输入；示例填草稿；已有用户不被强迫重新引导 |
| 交代 | 用户消息立即出现；必要许可可关闭、找回；无无关系统权限 | 允许原意图一次；拒绝保留输入；已给范围和来源不重复问 |
| 开始 | “会整理成三条结论和对比表，保留来源。”＋一行工作摘要 | 非阻断默认值可以改；缺关键用途才提一个问题 |
| 等待 | 当前真实步骤或“需要你补充……”；读正文不被拉走 | 继续阅读/离开；卡就绪可操作；只在已证明的受理与持续执行能力成立时承诺离开后继续 |
| 调整 | “修改：公开资料报告”关联条＋修改草稿＋退出入口 | 明确发送；在安全点应用；普通聊天草稿分别保存；已发生效果留记录 |
| 决定 | 一张当前待决卡；点开完整动作、目标、参数、影响、期限 | 改参数/允许/拒绝/稍后；旧批准失效；真实写回执才成功 |
| 查收 | 一句话说明交付了什么＋成果标题与摘要；打开后先内容 | 来源、版本、复制/分享、继续修改都可找到；部分完成说明缺项 |
| 回来 | 保留阅读位置；必要时一条“你离开后：报告已保存” | 点入同事项；仅真实变化形成摘要；无变化不制造欢迎消息 |
| 持续跟进 | 手机上看明白触发条件、下次时间、静默与停止 | 默认折叠预算等高级细节，但确认摘要含约定；暂停无新检查，历史成果保留 |

工作摘要、待决卡和成果卡是同对象在不同阶段的呈现。历史里的旧卡保留但压缩；不能每收到一个执行事件就插入一张新的大卡。普通问答直接正文；表帮助比较、图帮助发现趋势、计算器帮助探索变量，不能为了展示能力把所有回答做成仪表盘。

## 视觉裁决

保留 A1、成对语义色、系统动态字体与现有间距。首页应像一个安静的阅读和交代空间：助理正文无大边框，用户消息轻底；工具活动次级；当前待决与可用成果有明确容器。每个区块一个最相关主动作，必要的停止/修改保持可发现；高亮、阴影、颜色都需服务于层级。

审批使用 sheet，内容可滚动，决定区在安全区；长表单进入原生详情；大字号下按钮纵排，不通过缩字解决。图表提供数据表与朗读摘要，纸面上的 17pt/44pt 不能代替实际键盘与VoiceOver路径。

Apple 当前材料指南将 Liquid Glass 用于导航与控件，强调内容层的区分和克制使用；据此保留稳定不透明阅读层，优先使用系统组件。[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。Apple 的生成式AI指南强调可修改/恢复结果和明确修正反馈；Catpaw把这些落实在同工作修改、版本保存和回执反馈。[Apple Generative AI](https://developer.apple.com/design/human-interface-guidelines/generative-ai?changes=lat__5)。

产品聚焦和减少概念是本次设计判断。其依据与Apple的目的、用户自主权、简洁和工艺原则一致，但不是Apple对Catpaw的评价。[Apple Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles/)。2027系统入口和视觉样式属于前瞻；不在本轮加入Siri/Spotlight/Widget/语音或新图标。

## 如何交付与评价

本轮只改规划、验收细则、启动prompt和人工提案；不启动实际开发Goal、不改变运行Goal、不调用模型/PG、不安装/部署/推送。原生源码与既有数据不在本轮修改。新增设计断言映射回既有U/FQ/CG，不增设一组会竞争的验收ID。

开发首片仍先验原路由；CP01作为第一条完整价值路径，不取代CP02/03。每片的审阅至少回答：用户能否独立识别当前事实、完成下一步、从关闭/失败/返回中继续，以及使用或找回成果。初次使用观察可以复用既有U/FQ测试窗口，参与者与真实操作另按具体授权执行；不能由开发者解释后记作独立理解。

同版G1质量通过后可向用户准确交付已证实能力；G2保留具名实测门，G3仍须两者成立。比较目标指导探索，不能驱使每页添加功能或用未测排名做产品承诺。
