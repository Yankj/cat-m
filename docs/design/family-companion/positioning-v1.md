# 小咪家庭助理 · 定位 v1（用户已确认 2026-10-23）

## 定位
首轮收窄为 **「替妈妈记住孩子所有事、到点不漏」的家庭事务大脑**。成长陪伴是第二层，等用户建立信任后再加。

## 用户
30–40 岁、孩子在幼儿园到小学阶段的妈妈；双职工，或全职但事务琐碎。手机不离身，但没有整块时间。不缺育儿知识，缺的是脑容量。

## 痛点（按痛感排序）
1. **信息碎且散落**：家长群、学校通知图、老师私聊、兴趣班调课混在一起，一刷就沉；最怕漏带材料、漏缴费截止、漏调课。
2. **心理负担**：所有安排都挂在妈妈一个人脑子里，累的是一直惦记。
3. **安排常变、连锁影响**：一节课调时间，接送、晚饭、其他课都要跟着动。
4. **每次从头交代背景**：通用 AI 不认识她家孩子、老师、班级，用两次就放弃。
5. **成长焦虑真实但低频**：需要前面积累的点滴才能答好。

## 核心诉求
> 随手丢给你，你替我记住、理清、提醒、跟进，别让我操心，也别出错。

## 三个重点
- **随手丢**：截图、语音、一句话即可交代，零整理。图片识别通知是第一核心功能。
- **不漏也不错**：宁可多问一句，不猜日期或班级；未确认不说「已安排」。可靠比聪明重要。
- **越用越懂这个家**：孩子、学校、老师、课表、习惯沉淀为家庭档案，不再重复交代。

## 首轮功能
1. **一个入口收所有**：输入框「+」= 拍照 / 截图 / 语音 → 抽出事项卡片（时间、孩子、要带什么、截止），一点确认。
2. **今天页 = 孩子当日日程单**：一屏看完谁去哪、几点接、带什么、待确认；输入框在底部。
3. **变动一键处理**：调课时列出受影响的接送与提醒，问「要一起改吗」，确认后才改。
4. **我们家档案**：孩子、班级、老师、常去地点、课表；可看、可改、可删；记忆被使用时标出来源。
5. **克制提醒**：仅「截止临近 / 要带东西 / 有冲突」三类；每天最多 1–2 条，并说明为什么现在提醒；21:00–08:00 安静。
6. **成长第二层**：日常记录顺手沉淀为观察，每周一份简短小结；不做焦虑营销，不做诊断。

## 首轮砍掉 / 隐藏
- 通用聊天入口、网页报告、模型切换先隐藏。
- 侧栏只留：今天、我们家、对话记录。
- 不做多人共享、实时语音通话、自动报名缴费。

## 验证
找一位真实妈妈使用两周，只看三个数：
1. 漏掉的事件数；
2. 重复交代背景的次数；
3. 被提醒后真正去办的次数。

三个数变好后，再扩展到多人与成长功能。
