## 参考如何使用

完整读取研究正文与颜色表，并查看六张内嵌图。原 DOCX 的 SHA-256 为 `e0af1f5e9e0685cd13956a173037faae191dee5e828278e3865b7b8e18d6c9a5`；原文、提取图与关系记录保留在本机忽略目录，未复制到公开设计目录。

研究将 1–3 图标为 Codex Remote 手机样本：白底连续正文、灰色工具摘要、浅灰输入面，以及局部蓝色能力引用和紫色发送。第4、5图分别是 ChatGPT 与 Grok 陈列图，第6图是 ChatGPT 全屏插件示意。黑底／灰面／黄色本人气泡来自研究描述的另一组用户参考，不能标成官方 Codex 样式。所有采样都不是官方 tokens，也不证明动态行为；本轮不重新核验研究中的商店版本或外部网页时效。

采纳的是区域角色：阅读面保持中性，输入和可交互内容用浅一级表面，重要动作以少量强调色定位。约 `#A57DF0` 的紫色仅作为图标发送按钮参考。它与白色的对比约3.09:1，不能直接用于普通大小白文字按钮；文字操作使用更深的紫色，审批确认使用清楚的黑白主按钮。黄色本人气泡本轮不默认采用。

## 本轮改变

| 区域 | 设计决定 |
|---|---|
| 正文 | 主体17px，结论21px，普通回答采用直接阅读排版；收掉原27px诗意标题与显眼靛蓝面。中文行高约1.7，段落间距22px。 |
| 用户消息 | 浅色轻灰、深色灰阶，靠右与圆角区分身份；助手正文没有整段外框。身份不占用执行／待决状态色。 |
| 智能交互 | 白／灰面与细分隔，评分条用中性深浅灰；紫色留给滑杆、明确继续和焦点。选中项还有轮廓与pressed语义，数字保留满分口径。 |
| 输入 | 浅灰或深灰输入面、稳定工具行、44px命中区；紫色发送与黑白审批决定分工。输入边界可识别，长字不挤掉动作。 |
| 抽屉 | 中性底，当前项有选中轮廓；历史项靠字号、间距与分组组织。正文、搜索与当前项没有不同的蓝色大板。 |
| 过程与资料 | 完成过程使用灰色摘要；单位、版本、字段、口径与过程辅助字从约10–12px提高到13–15px起点。源SVG插图保持原身份。 |
| 审批 | 主体、对象和字段中性呈现；确认用黑白高对比按钮，修改保持紫色，拒绝有文字与错误语义色。关闭／稍后仍不等于拒绝。 |
| 浮层 | 中性透明材料与细边界，源按钮空间关系保留；关闭、grabber、正文与固定决定区各有明确角色。 |

页边20px、交互面圆角18px、输入圆角25px、审批顶部28px是样机调试值；正式实现映射语义字号与系统安全区，不把浏览器像素当iPhone pt。放大文字仍是网页示意，最大Dynamic Type与VoiceOver需要原生验证。原生滚动、Sheet、zoom、键盘和玻璃继续用平台机制。

## 色彩与可读性

| 语义 | 浅色 | 深色 |
|---|---|---|
| 阅读底 | `#FFFFFF` | `#0D0D0D` |
| 正文 | `#202020` | `#F2F2F2` |
| 辅助正文 | `#626262` | `#A3A3A3` |
| 输入／内容面 | `#F7F7F7` | `#212121` |
| 智能交互面 | `#F7F7F7` | `#181818` |
| 文字操作／焦点 | `#6D45B8` | `#B7A0F3` |
| 图标发送底 | `#A57DF0` | `#A57DF0` |
| 发送箭头 | `#FFFFFF` | `#16121D` |
| 确认按钮 | 黑底白字 | 白底深色字 |

正文与辅助文本计算超过4.5:1，必要选中轮廓、图条与发送箭头超过3:1。浅色白发送箭头余量较少，使用2px清楚线条，不叠加降低透明度；它不是白文字按钮。装饰性卡片分隔与评分背景轨道可以低强调，分数、对象名和满分100的文字保持可读。错误同时有文字，颜色不承担唯一含义。具体计算见JSON；这属于不透明语义色计算，不能代替系统玻璃合成取色。

## 实现与证据边界

R4.1 只增加HTML与样式覆盖层，直接引用原 R4 的 `motion.js`、`app.js`、基础CSS和SVG。原引擎不复制、不修改；此次复查新的布局、文字和前景可达性，不把旧13项数值测试宣称为新原生测试。原图与生成图不重绘，A1、冻结tokens／HTTP、原生宿主、模型和后台不变。

正式源码优先把本轮角色映射到现有 Swift 语义样式，复用系统字体、safeAreaInset与presentation。颜色不能授予effect，也不能把等待／unknown画成成功。样机内容、草稿、日程与回执仍为RAM人工样例；本轮不证明原生光学材质、触觉、键盘、持久恢复或真实执行。版本截图与浏览器结果见[日期证据](../acceptance/evidence/codex-color-20261013-r4-1/RESULT.json)。
