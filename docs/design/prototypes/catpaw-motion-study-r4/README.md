# cat：UX-1 R4 交互与动效样机

2026-10-13。效果评审用的独立设计样机，没有复制生产 App 或替换维护入口。公开源代码放在设计目录，原生实现仍只回 `apps/ios-conversation`。

本地预览从仓库根运行：

```sh
python3 -m http.server 8849 --bind 127.0.0.1 --directory docs/design
```

打开 http://127.0.0.1:8849/prototypes/catpaw-motion-study-r4/ 。预览仅绑定本机。直接打开 `index.html` 也可以操作主体；复制依赖浏览器的剪贴板权限。

## 先体验这一条路径

1. 写一句草稿，从左边缘慢慢拖开抽屉；半途反向，或松手后再次抓取。短慢拖回原位，速度也参与吸附；草稿不丢。
2. 点「连续进入与返回」，从详情左边缘短拖会取消，长拖返回原成果位置；此时抽屉手势不参与。
3. 点「需要你时，清楚一点」，拖 grabber 从中档到大档，再拖回。确认按钮的纵坐标保持不变，只有正文阅读面积改变。grabber 可以用 Enter/Space 或点按切档。
4. 修改标题，关闭，再打开修改页，草稿仍在；保存才形成演示新版本，需要重新确认。关闭／稍后／拒绝分别处理。确认只写人工回放状态，不创建日程。
5. 点「从这里，展开」，图片从源缩略图连续展开。向下拖可返回，反向向上拖可回大图，取消回原目标；关闭中也能接手。
6. 菜单围绕触发对象显示。成果支持长按／右键菜单；关闭后焦点回到当前可用的来源或前景控件。
7. 展开可观察过程，停止正文与暂停工作是独立动作。修改权重立即本地更新；「用这个偏好继续」只放入关联草稿。

## 文件分工

`motion.js` 是呈现用解析弹簧和 pan 方向协调；同一属性的目标改变保留当前速度，大帧间隔不会因显式积分变得不稳定。`app.js` 只管理人工视图状态；动画完成只清理 presentation，不授予 effect 或 task authority。`style.css` 是新的暖白／深靛蓝阅读方向，不以延伸旧 R3 布局为前提。

原生行为与相对成本见 [R4 原生实施附录](../../native-interaction-motion-r4.md)，视觉与参数见 [R4 设计方向](../../interaction-motion-r4.json)。[R3](../catpaw-interaction-r3/index.html)继续保存完整对象状态与42项场景索引；本样机聚焦此前没被充分验证的连续机制，不声称重新覆盖全部验收。

两张独立视觉方向图由 taste-skill 的 `imagegen-frontend-mobile` 生成，图中的研究任务和样机中的周末安排是不同的人工样例，采用同一阅读与审批结构。PNG 不是原生像素规范，也不能证明触控、玻璃或动效。[生成来源](assets/concepts-provenance.json)、[完整提示词](assets/concept-generation-prompts-r4.md)保留，A1 图标未替换。山间封面为本轮代码绘制的 SVG 插图，不是照片或真实景点图。

## 计算与证据边界

比较沿 `weighted_comparison_v1` 的已知维度加权结构，采用人工数据：龙王山的安静／路程分为95／65，莫干山为65／95。权重为 `w` 与 `100-w`，结果是 `Σ(score×weight)/100`，单位为偏好分／100。70% 时为86.00／74.00，30% 时为74.00／86.00。本样例整数分与整数权重的结果精确到百分位；生产的十进制／bankers／输入校验合同保持原样。调参数没有请求，也不保存记忆。

消息列表和 Sheet 正文使用浏览器自身滚动，没有在网页重写惯性、回弹或 iOS 滚动物理。原生采用系统 ScrollView/UIScrollView，Liquid Glass、scroll edge、键盘、触觉与共享元素转场采用系统 API；网页的 blur 只能示意半透明材质。减弱动态去掉惯性尾段与长距离图片 zoom，降低透明度改实色，大文字使审批进入大档。

所有内容、过程、状态、日程与回执是人工样例，只存在 RAM，刷新重置。没有模型、Auth、日历、通知、云端执行、冷启动恢复、pinch-to-zoom 或原生多手势验收。交互检查是浏览器／数值合成证据，不能关闭 AF-U、CG、FQ、CP 或 FINAL-G3。
