# Catpaw-M v1.0 发布说明

## 亮点
- **首次启动更顺滑**：只有首次安装时显示开屏动效和欢迎页。毛绒小猫领场，点「开始使用」后按钮会变成输入框，聊天内容依次浮现。开启“减弱动态效果”时改为淡入。之后每次启动直接进入聊天，白屏加载页已经去掉。
- **预设场景**：空对话里有几张场景卡，点一下就能直接发送，帮你快速体验出门提醒、记忆、主动建议等核心能力。
- **GitHub / Google 登录**：除了体验账号，现在还可以用 GitHub 或 Google 登录，也可以把体验账号绑定到这两个账号上。
- **「打扰到我」反馈修复**：点了不会再报错，之后的主动提醒会降级处理。
- **发送更稳**：重新同意模型服务条款后立即发送，不会再卡 60 秒。遇到短暂繁忙时，后台会静默重试，用户只会看到气泡上的小转圈。
- **品牌启动画面**：启动时屏幕中央显示 96pt 的 Catpaw 图标，聊天准备好就淡出，最多停留 1.5 秒。刘海屏 iPhone 上聊天页不再出现上下黑边。
- **聊天体验**：顶部可以切换模型，发送和停止时有触感反馈，处理中有微光提示。灵动岛实时活动重新设计，标题就是你的任务内容。
- **对话上下文**：追问建议只出现在最新一条回答下面。确认卡片（例如日历、提醒）在取消或完成后会一直显示「已取消」「已加入日历」等最终状态，换轮次或重新打开 App 都不会丢。
- 已经包含在 792587e 里的能力：深色模式下文字可读、品牌动效、记忆与「使用记忆」开关、主动建议四级触达、设备操作确认与撤销、Gemini 默认路由和服务商披露。

## 已知风险（v1）
1. **APNs 密钥没配齐**：`/health` 返回 `apns:false`，补齐之前所有服务端推送都会失败（apns_not_configured）。需要用户补齐其中一整组密钥：APNS_* 或 CATPAW_APNS_*。
2. 主动推送相关数据以**明文存在 UserDefaults**，加密（L2）放到 v1.1。
3. **暂不支持 Apple 登录**（Sign in with Apple），延后到 v1.1。
4. 模型服务如果卡死，没有降级方案；演示时请准备预录视频。
5. 生产库里留有冒烟测试数据：两个匿名测试用户，等验收后再决定是否清理。
